# 디자인 규약

모든 출력 페이지(summary.html, study.html, 앞으로 생길 페이지)는 한 도구에서 나온 것처럼 보여야 한다. 그래서 색, 글자, 간격 값은 `assets/base.css` 한 곳에만 두고, 각 페이지 틀은 그 이름만 쓴다.

기준 디자인은 학습 보기(2026-10-29)다. 다크 모드 버튼, 글꼴 불러오기, 키보드·움직임 줄이기 대응이 가장 잘 되어 있어서다.

## 원칙

1. **값은 base.css에만 둔다.** 페이지 틀(`assets/*-template.html`)에 색 코드(`#…`, `rgb(…)`)나 px 글자 크기를 직접 쓰지 않는다. 필요한 값이 없으면 base.css에 토큰을 더하고 이 문서 표에도 적는다. 이유: 값이 틀마다 흩어지면 6월 요약 페이지와 10월 학습 보기처럼 강조색·배경·둥글기가 서로 달라진다.
2. **결과물은 파일 하나로 열린다.** 렌더러가 base.css를 `{{BASE_CSS}}` 자리에 그대로 넣는다. 외부에서 불러오는 것은 Pretendard 글꼴 하나뿐이고, 인터넷이 없으면 시스템 글꼴로 대체된다.
3. **점검으로 지킨다.** `scripts/check_design.py`가 틀 파일에서 규약 위반(직접 쓴 색·px 글자 크기, base.css에 없는 토큰 이름)을 찾는다.

## 토큰

### 색 — `light-dark(밝은 값, 어두운 값)`로 한 번만 적는다

| 토큰 | 용도 |
|---|---|
| `--bg` `--surface` `--sunken` | 페이지 배경 · 카드 · 눌린 면 |
| `--line` `--line-strong` | 구분선 |
| `--ink` | 제목 |
| `--body` | 본문 |
| `--muted` | **가장 옅은 글자색.** 시간·개수·설명 (배경 대비 4.5:1 이상) |
| `--faint` | **선·아이콘 전용. 글자에 쓰지 않는다** (밝은 화면 대비 2.4:1이라 읽기 어렵다) |
| `--accent` `--accent-ink` `--accent-soft` `--on-accent` | 강조 · 강조 위 글자 · 옅은 강조 면 · 강조 버튼 위 글자 |
| `--key` `--key-soft` `--key-line` | "핵심" 상자 (초록) |
| `--note` `--note-soft` `--note-line` | "해설·주의" 상자 (주황) |
| `--media` `--on-media` | 영상 화면·썸네일의 검정 바탕과 그 위 글자 (밝기 전환과 무관) |

밝기 전환: 처음엔 컴퓨터 설정을 따르고, 버튼을 누르면 `<html data-theme="light|dark">`가 붙는다. 선택은 `localStorage`의 `yvs:theme`에 저장해 모든 페이지가 공유한다.

그림자는 `--shadow`(카드·서랍), `--shadow-sm`(눌린 면 위 선택된 버튼·썸네일), `--shadow-media`(영상 위 재생 버튼) 세 가지다.

### 글자 — rem 8단계 (브라우저 글자 크기 설정을 따르게)

| 토큰 | 크기 | 쓰는 곳 |
|---|---|---|
| `--fs-xs` | 12px | 시간, 개수, 작은 이름표 |
| `--fs-sm` | 13px | 버튼, 목차 |
| `--fs-md` | 14px | 보조 설명 |
| `--fs-base` | 16px | 본문 |
| `--fs-lg` | 20px | 리드 문장, 핵심 상자 |
| `--fs-xl` | 26px | 묶음·챕터 제목 |
| `--fs-2xl` | 34px | 항목 제목 |
| `--fs-display` | 32~48px | 페이지 제목 |

굵기는 `--fw-regular`(400) `--fw-semibold`(600) `--fw-bold`(700) `--fw-heavy`(800) 네 가지만 쓴다.

### 모양과 간격

- 둥글기: `--r-sm`(8, 버튼·칩) `--r-md`(12, 카드·이미지) `--r-lg`(14, 영상 화면) `--r-pill`(알약)
- 간격: `--s-1`~`--s-16` (4px 배수: 4, 8, 12, 16, 24, 32, 48, 64)
- 틀: 왼쪽 목차 `--side` 272px, 상단 바 `--top` 60px, 읽기 단 `--read` 760px
- 화면 폭 기준은 두 개만: 1100px(본문 배치 조정), 900px(목차를 서랍으로)

## 공통 부품 (base.css에 정의)

| 부품 | 클래스 | 설명 |
|---|---|---|
| 틀 | `.side` `.topbar` `.main` `.wrap` | 왼쪽 목차 + 상단 바(제목, 밝기 버튼) |
| 페이지 머리 | `.intro` `.eyebrow` `.sub` `.src` | 분류 글씨, 제목, 부제, 원본 영상 칩 |
| 목차 | `.nav` `.no` `.active` | 번호 + 제목, 지금 보는 곳 강조 |
| 시간 칩 | `.time-chip` | 누르면 원본 영상의 그 지점으로 이동 |
| 상자 | `.callout.key` `.callout.note` | 핵심 / 해설·주의 |
| 점 목록 | `.points` | 강조색 짧은 막대 |
| 그림 | `.figure` | 이미지 + 시간 링크가 달린 설명 |
| 프롬프트 | `.prompt` `.copy` | 복사 버튼 달린 카드 |
| 맨 아래 | `.site-foot` `.btn` | 생성 시각, 도구 링크, 원본 영상 버튼 |

모든 페이지는 맨 아래에 "youtube-visual-summary로 만듦" 링크를 단다. 공유된 페이지에서 저장소로 오는 길이다.

## 새 출력 페이지를 만들 때

1. `assets/<이름>-template.html`의 `<style>` 맨 위에 `{{BASE_CSS}}`를 두고, 그 아래에는 그 페이지에만 필요한 배치만 쓴다.
2. 렌더러에서 `common.load_page_template("<이름>-template.html")`로 틀을 읽는다. base.css가 `{{BASE_CSS}}` 자리에 들어간 문자열이 돌아온다. 도구 링크는 `common.TOOL_URL`.
3. `scripts/check_design.py`를 돌려 위반이 없는지 확인한다.
